# CPP Modules

Collection of C++ projects developed as part of the 42 school curriculum, progressively covering the core concepts of object-oriented programming and modern C++.

## Goal

Move from C to C++ by exploring the language's fundamentals: classes, memory management, inheritance, polymorphism, templates, and standard containers — while learning to write clean, idiomatic C++ code.

## Concepts covered
- Classes, constructors/destructors, member functions
- Encapsulation and the orthodox canonical form
- Inheritance and polymorphism
- Abstract classes and interfaces
- Templates (function and class templates)
- Manual memory management (RAII, dynamic allocation)
- Exception handling
- Standard Template Library (STL): containers, iterators, algorithms

## Tech stack
- Language: C++ (C++98)
- Standard: compliant with the 42 Norm

## Build
Each module is compiled independently with its own Makefile:
```bash
cd moduleXX
make
```
